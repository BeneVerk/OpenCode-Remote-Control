## Actors

- **You (developer)** — own all the machines; one identity (Cloudflare Access, or a self-hosted gate).
- **Browser** — the only client; never types per-machine URLs (the Fleet generates them).

## External systems

- **Cloudflare Access** — the auth gate in cloud mode (email OTP / OIDC); pluggable in self-hosted mode.
- **cloudflared tunnels** — each machine exposes its opencode web-UI on a tunnel hostname; the Fleet proxies it.
- **opencode** — runs untouched on each machine; one web-UI per machine serves all that machine's sessions.
- **D1 + KV** — registry (machines, sessions, notifications) + edge-cached `machine → backend` map.
- **LLM providers** — called by opencode on the machine; the Fleet never touches that traffic.

## Key invariant

The Fleet **aggregates + authenticates + proxies**; it never runs opencode or
touches model traffic. Execution stays on the originating machine — the cloud
only relays.
