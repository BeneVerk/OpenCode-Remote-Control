## What it is

Opencode Remote Fleet is a **remote control + aggregation plane** for
[opencode](https://opencode.ai) coding-agent sessions running across all your
machines. One domain (`opencode.beneverk.com`) gives you a single dashboard of
every machine + every active session, with live status and **notifications**
("session waiting for input/approval") that deep-link you straight to the
session that needs you.

## What you get

- **One pane of glass** — machines and their sessions, grouped, with live status.
- **Notifications** — when a session needs an answer, the Fleet tells you; one click lands you in it.
- **Unmodified opencode UI** — served transparently, per machine, behind the same auth gate.
- **Auth-gated** — Cloudflare Access (cloud) or a pluggable self-hosted gate.
- **Self-hostable** — the same core runs on your own machine (Deno), exposed via tunnel or static IP.
