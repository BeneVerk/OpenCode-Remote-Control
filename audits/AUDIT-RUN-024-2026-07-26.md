## Regression check (did the fixes introduce new defects?)

- **`BACKEND_SUFFIXES` config-dependency (observation, not a defect):** the R3 allowlist defaults to `cfargotunnel.com`. If a deployment uses a **custom** tunnel hostname (e.g. `desktop-tunnel.beneverk.com`), registration will 400 unless `vars.BACKEND_SUFFIXES` is extended in `wrangler.jsonc`. Documented in `Env` interface + the audit; user-actionable, not a regression.
- **Origin check vs future workers.dev:** if `workers_dev` is ever re-enabled, browsers reaching the `*.workers.dev` URL would have an Origin matching that host (≠ `opencode.beneverk.com`) and be rejected by R10. Intended behavior (canonical-only), not a regression.
- **PBKDF2 latency:** ~100 ms added per password-hashing register (only when a session password is set). Acceptable.
- **No functional regressions** in `tsc`, dry-run, the 8 tests, or the live probes (register/list still work end-to-end).
